# Lesson 1: Classes and Objects

## Goal

Model a simple real-world concept with a class. Keep data private and expose only the operations callers need.

## Exercise

Open `starter.cpp` and implement a `Book` class with a title and author. Add a constructor, read-only getters, and a `printDetails()` method. In `main()`, create a book and print its details.

Compile and run this lesson from this directory:

```sh
clang++ -std=c++17 starter.cpp -o lesson1
./lesson1
```

(Use `g++` instead of `clang++` if that is your installed compiler.)
